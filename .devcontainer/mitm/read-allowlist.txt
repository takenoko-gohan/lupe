# =============================================================================
# Destination domains allowed for read methods (GET/HEAD).
#
# Format: one entry per line, either "domain" or "domain<whitespace>path-pattern".
# Everything after # is a comment.
#   *                        allow every domain (usable only in this file)
#   .example.com             leading dot = matches subdomains and the apex / every path
#   example.com              no dot = exact match (subdomains are not included)
#   .example.com  /docs/*    prefix match; only paths starting with /docs/
#   .example.com  */index    suffix match
#   .example.com  /health    exact match
# Paths are matched case-sensitively with the query string removed. * is allowed once, at
# the start or end.
# A malformed domain field ("*.example.com" where ".example.com" was meant, etc.) is an
# error at startup.
#
# This file is bind-mounted into the mitm container, so after editing it no rebuild is
# needed: `restart mitm` is enough (edit it on the host).
# If something is denied, run `docker logs devcontainer-mitm-1 | grep read_not_allowed`
# to find the destination and add it here.
# =============================================================================
